# User Management API

Backend REST API for managing users using Spring Boot, Java 17, and MySQL.

## 🚀 Features

* Create User
* Get All Users
* Update User
* Delete User

## 🛠️ Tech Stack

* Java 17
* Spring Boot
* Spring Data JPA
* MySQL
* Maven

## 📦 API Endpoints

### GET Users

GET /users

### POST User

POST /users

### PUT User

PUT /users/{id}

### DELETE User

DELETE /users/{id}

## ⚙️ Setup

1. Create database:

```
CREATE DATABASE db_user;
```

2. Configure application.properties

3. Run:

```
mvn spring-boot:run
```
